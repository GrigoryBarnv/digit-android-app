## Download the APK

The latest APK is built automatically when changes are merged into `main`.

[Download the latest APK](https://github.com/lasr-lab/opentouchapp/releases/latest/download/opentouchapp-release.apk)

## CI flow

- Pull requests to `main` run the Android CI workflow and build a debug APK.
- Pushes to `main` run the release workflow and publish the APK as a GitHub Release asset.
