OpenTouch model converter
=========================

Purpose
-------
This small tool creates the model package that the OpenTouch Android app can
import. It combines:

  1. an ONNX model file (.onnx), and
  2. a JSON configuration file (.json)

into one ZIP-based file with the custom extension .opentouchmodel.

The generated package contains exactly:

  model.onnx
  model.json

The Android app recognizes those names and extracts them into its private model
directory. This converter does not train or export an ONNX model. Export the
model first, then package it here.

Requirements
------------
* Python 3.10 or newer
* No Python packages need to be installed; the script uses the standard library

Check Python on Windows:

  py --version

Check Python on macOS/Linux:

  python3 --version

Configuration format
--------------------
The JSON must contain the values read by the Android ONNX runner:

  {
    "input_width": 224,
    "input_height": 224,
    "color_order": "RGB",
    "mean": [0.485, 0.456, 0.406],
    "std": [0.229, 0.224, 0.225],
    "labels": ["key", "finger"],
    "output_type": "logits"
  }

Use the dimensions and normalization values used when the model was trained.
The labels must be in the same order as the ONNX output classes. The app applies
softmax, so output_type must be logits. RGB is required because the Android
runner supplies RGB input planes.

Create a package on Windows
---------------------------
Run these commands from the repository root:

  py model_converter\convert_model.py ^
    --model model_key_finger\output\key_finger.onnx ^
    --config model_key_finger\output\model_config.json ^
    --output model_key_finger\output\key_finger.opentouchmodel

The output is placed beside the model automatically if --output is omitted:

  py model_converter\convert_model.py ^
    --model path\to\my_model.onnx ^
    --config path\to\my_model.json

Create a package on macOS/Linux
--------------------------------
Run from the repository root:

  python3 model_converter/convert_model.py \
    --model model_key_finger/output/key_finger.onnx \
    --config model_key_finger/output/model_config.json \
    --output model_key_finger/output/key_finger.opentouchmodel

If the output already exists, the script stops rather than overwriting it. Add
--force only when replacing an existing package is intentional.

Install in the Android app
--------------------------
Transfer the generated .opentouchmodel file to the Android device, then open it
with OpenTouch, or use the app's AI menu and choose Import model files. The app
will extract model.onnx and model.json and make the model available for Analyze.

Troubleshooting
---------------
* "must have a .onnx/.json extension": check the input file names.
* "missing required field": add input_width, input_height, mean, std, or labels.
* "labels": make sure every class has a non-empty, unique name.
* "output_type": the current Android runner expects raw logits, not probabilities.
* The converter cannot fix an incompatible ONNX graph. The graph still needs to
  accept [1, 3, input_height, input_width] float32 RGB input and return one logit
  per label.
